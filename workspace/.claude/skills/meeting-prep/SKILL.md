# آمادگی و پیگیری جلسه

## قبل از جلسه
### ۱. پیدا کردن جلسه
- اگر `mcp__google__*` هست: رویداد را از تقویم بگیر (زمان، شرکت‌کنندگان، توضیحات، لینک). چند جلسه شبیه → یک سؤال.
- اگر نیست یا رویداد پیدا نشد: از گفته کاربر استفاده کن؛ فقط اگر «با چه کسی و درباره چه» معلوم نیست، یک سؤال بپرس.

### ۲. زمینه — یک دور موازی
- **افراد:** برای هر شرکت‌کننده `notes/people/` را Grep کن (اسم، ایمیل، شرکت) — روش و قالب در skill `people-crm`:
  نقش، ترجیحات، آخرین تماس، پیگیری‌های باز، قول‌هایی که داده شده.
- **مشتری/پروژه:** `project_list` با `client` = نام مشتری (وضعیت، مهلت، ساعت ثبت‌شده، `next_action`) و در صورت
  نیاز `client_list`.
- **یادداشت‌ها:** Grep نام مشتری/پروژه در `notes/work/` (جلسه‌های قبل، تصمیم‌ها).
- **ایمیل** (اگر Gmail هست): ۳ تا ۵ ایمیل اخیر با شرکت‌کنندگان. **GitHub** (اگر وصل است و جلسه فنی است):
  issue/PRهای مرتبط.
- نوع جلسه: مصاحبه Upwork/مشتری خارجی → نکات skill `upwork-growth`/`client-acquisition` و پیشنهاد تمرین چند جمله
  انگلیسی با `english-coach`؛ جلسه فنی/معماری → نکات کلیدی از `agent-architect` اگر لازم است.

### ۳. خروجی (کوتاه، بدون جدول)
```
🗓 **{عنوان} — {روز، ساعت}** با {افراد}
🎯 **هدف جلسه:** {یک جمله: بعد از جلسه چه چیزی باید روشن شده باشد}
👤 **افراد:** {اسم — نقش — نکته مهم/ترجیح — آخرین تماس}
📎 **زمینه:** • {۳ تا ۵ نکته: وضعیت پروژه، قول‌های باز، آخرین ایمیل}
📋 **دستور جلسه:** 1) ... 2) ... 3) ...
❓ **سؤال‌هایی که بپرسی:** • ...
⚖️ **تصمیم‌های لازم:** • ... (برای مذاکره قیمت/محدوده: حداقل قابل‌قبول را از قبل مشخص کن)
```
اگر برای جلسه یادآوری نیست، یک سؤال: «۳۰ دقیقه قبلش یادآوری بذارم؟» `[[options: ⏰ بذار | ❌ نه]]`
→ `reminder_add` با متن «جلسه با X — لینک/نکته اصلی».

## بعد از جلسه (یادداشت، ویس یا «جلسه تموم شد»)
1. استخراج کن: خلاصه ۳ خطی، تصمیم‌ها، action itemها (**مسئول + مهلت**)، قول‌های طرف مقابل، اعداد (قیمت، مهلت، محدوده).
   چیزی که نگفته را نساز؛ مهلت مبهم → «بدون مهلت» و یک سؤال در پایان.
2. ذخیره: `notes/work/YYYY-MM-DD-meeting-<topic>.md` (خط اول خلاصه یک‌جمله‌ای؛ سپس تصمیم‌ها، اقدام‌ها، نکات باز).
3. ثبت‌ها (موازی):
   - action itemهای کاربر → `task_add` (due، priority، area=work)
   - مشتری/پروژه → `project_upsert`: وضعیت (مثلاً interview → active)، `next_action` + `next_action_date`، نرخ/مهلت توافق‌شده
   - هر شرکت‌کننده → فایل `notes/people/<slug>.md`: «آخرین تماس» = امروز + موضوع، ترجیحات تازه، پیگیری‌های باز
     (طبق `people-crm`)
4. پاسخ کوتاه: «ذخیره شد: {n} کار، پروژه X به‌روز شد، فایل جلسه: ...» و **یک** سؤال:
   «ایمیل follow-up برای {افراد} پیش‌نویس کنم؟» `[[options: ✍️ بنویس | ❌ لازم نیست]]`
   پیش‌نویس اول در چت (مشتری خارجی: انگلیسی، کوتاه، با خلاصه تصمیم‌ها و قدم بعدی)؛ ارسال فقط با تأیید کاربر.
