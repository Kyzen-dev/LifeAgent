# بازبینی هفتگی (شنبه تا جمعه)

## جمع‌آوری
- کارها: انجام‌شده این هفته (`task_list` status=done) و باز/عقب‌افتاده.
- عادت‌ها: `habit_status` (done_this_week در مقابل target).
- سلامت: `health_history` برای شاخص‌هایی که ثبت می‌شوند (۷ روز).
- ژورنال: `journal_recent` days=7 — روند حال و انرژی، موضوعات تکراری.
- مالی: `finance_list_transactions` از شنبه تا امروز + `finance_summary` ماه جاری برای وضعیت بودجه.
- اهداف: `goal_list`.
- فریلنس: `time_report` هفته، `project_list` (status=all برای تغییرات هفته)، درآمد فریلنس ثبت‌شده؛ تعداد outreach/پروپوزال‌ها (skill `client-acquisition`).
- برند: `notes/brand/log.md` — پست‌های این هفته (skill `personal-brand`).
- وزن: `health_history` metric=weight days=30 — روند نسبت به هدف (skill `healthy-gain`).
- تقویم هفته آینده و GitHub (اگر وصل است): رویدادهای مهم، PR/issueهای باز کاربر.

## خروجی
1. **🏆 دستاوردها** (۳ تا ۵ مورد)
2. **🌱 عادت‌ها و سلامت** — اعداد + یک نکته
3. **💰 مالی هفته** — جمع هزینه، بزرگ‌ترین دسته‌ها، هشدار بودجه
4. **💼 فریلنس** — ساعت کار، نرخ مؤثر ساعتی، وضعیت pipeline (lead/proposal)، مهلت‌های هفته بعد
5. **📣 برند و انگلیسی** — پست‌های منتشرشده، تمرین‌های انگلیسی، یک پیشنهاد برای هفته بعد
6. **🎯 اهداف** — پیشرفت و اینکه کدام عقب است
7. **🔍 الگوها** — یک مشاهده صادقانه (مثلاً «سه‌شنبه‌ها همیشه کم‌انرژی هستی»)
8. **📌 هفته بعد** — ۳ اولویت پیشنهادی + رویدادهای مهم

در پایان بپرس آیا اولویت‌ها را تأیید می‌کند تا به‌صورت task ثبت کنی و درصد پیشرفت اهداف را به‌روز کنی.
خلاصه را در `notes/reviews/YYYY-MM-DD-weekly.md` ذخیره کن.
