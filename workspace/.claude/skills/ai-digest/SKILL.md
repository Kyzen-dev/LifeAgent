# AI Digest — خلاصه هفتگی

## جمع‌آوری (۷ روز اخیر؛ با WebSearch/WebFetch، موازی با subagent `researcher` اگر حجم زیاد است)
- **مدل‌ها و پلتفرم‌ها:** اعلان‌های Anthropic، OpenAI، Google (Gemini/DeepMind)، Meta، Mistral، DeepSeek/Qwen و مدل‌های open-weight مهم؛ قیمت و قابلیت‌های جدید API.
- **استک کاربر:** صفحه releases در GitHub برای `langchain-ai/langgraph` و `langchain-ai/langchain` (و langsmith اگر مرتبط) — تغییرات مهم و **breaking changes**؛ همچنین MCP و فریم‌ورک‌های agent رقیب.
- **ابزار و پژوهش:** موارد پربحث Hacker News و Hugging Face papers درباره agents، RAG، eval، inference؛ وبلاگ‌های فنی معتبر.
- `notes/learning/ai-digest/` را Grep کن تا موارد هفته قبل تکرار نشود.

هر خبر باید منبع و تاریخ داشته باشد. شایعه و ادعای تأییدنشده را جدا علامت بزن.

## خروجی (حداکثر حدود ۳۰ خط)
**🤖 خلاصه AI — هفته {تاریخ شمسی}**
1. **مهم‌ترین‌ها (۵ تا ۸ مورد):** عنوان — یک خط چه شده — یک خط «برای تو یعنی چه» (کار فریلنس، پروژه‌های فعلی، مهارت‌ها). لینک.
2. **استک تو:** نسخه‌های جدید LangGraph/LangChain و اینکه آیا پروژه‌های فعالش (`project_list`) تحت تأثیرند.
3. **امتحان کن:** یک ابزار/تکنیک مشخص برای این هفته با زمان تقریبی.
4. **ایده پست:** ۳ ایده برای LinkedIn/X (زاویه شخصی، نه بازنشر خبر) → اگر کاربر خواست، با skill `personal-brand` پیش‌نویس کن.
