# نقشه توسعه LifeAgent

نقشه راه برای اینکه دستیار از «کار می‌کند» به «حرفه‌ای، خودکار و قابل‌اعتماد» برسد.
اندازه کار: **S** = چند ساعت، **M** = ۱ تا ۳ روز، **L** = یک تا دو هفته، **XL** = بیشتر.
ارزش: ★ تا ★★★.

## اصول توسعه
1. **اول اندازه بگیر، بعد اضافه کن.** هر قابلیت جدید باید یک معیار موفقیت داشته باشد (مثلاً «نرخ مصاحبه Upwork»، «روزهایی که هزینه‌ها ثبت شد»).
2. **هر قابلیت = skill + ابزار + تست.** رفتار در `workspace/.claude/skills/`، عملیات داده در `lifeagent/tools/`، و تست در `tests/`.
3. **هزینه را بپا.** قبل و بعد از هر تغییر، `/cost` و مصرف توکن را مقایسه کن.
4. **حریم خصوصی.** داده شخصی فقط روی سرور خودت؛ ریپو عمومی است.
5. **کارهای بیرونی همیشه با تأیید.** خودکارسازی بیشتر نباید از مسیر تأیید عبور کند.

## روش کار برای هر تغییر
1. یک session جدید Claude Code روی ریپو باز کن و تغییر را توضیح بده (Claude روی شاخه جدا کار می‌کند).
2. Claude تست می‌نویسد و `pytest` را اجرا می‌کند؛ بعد از push، **CI** خودکار image را برای amd64 و ARM می‌سازد و smoke test را اجرا می‌کند.
3. وقتی CI سبز شد، merge کن.
4. روی سرور: `bash deploy/setup-server.sh` — کد را می‌گیرد، image را می‌سازد، ری‌استارت و چک سلامت می‌کند.
5. تغییر schema دیتابیس فقط از طریق `MIGRATIONS` در `lifeagent/db.py` (داده‌های قبلی حفظ می‌شوند).
6. skill جدید یا بهتر: از خود ربات بخواه با skill `skill-creator` بسازد، یا در Claude Code بنویس.
