# راهنمای راه‌اندازی رایگان و تست LifeAgent

سه مسیر رایگان، به ترتیب پیشنهاد:

| مسیر | مناسب برای | هزینه | محدودیت مهم |
|---|---|---|---|
| **A. GitHub Codespaces** | تست سریع (همین امروز) | رایگان: ۱۲۰ core-hour در ماه (حدود ۶۰ ساعت با ماشین ۲ هسته‌ای) | فقط وقتی codespace روشن است کار می‌کند؛ روال‌های زمان‌دار (گزارش صبح و…) فقط در همان بازه اجرا می‌شوند |
| **B. Oracle Cloud Always Free** | اجرای دائمی ۲۴ ساعته | رایگان: VM آرم تا ۴ هسته و ۲۴ گیگ رم | ثبت‌نام کارت بین‌المللی می‌خواهد؛ گاهی «Out of capacity»؛ VM کم‌مصرف ممکن است پس گرفته شود (پایین‌تر) |
| **C. Google Cloud e2-micro** | جایگزین دائمی | رایگان در چند region آمریکا | فقط ۱ گیگ رم (اسکریپت swap اضافه می‌کند)؛ build کندتر |

> تست روی کامپیوتر خودت در ایران مناسب نیست: Telegram API و Anthropic API از داخل ایران در دسترس نیستند. سرور باید خارج باشد.

> **مهم:** هر توکن ربات تلگرام فقط در **یک** جا می‌تواند همزمان اجرا شود (وگرنه خطای `Conflict`). برای تست در Codespaces یک **ربات تستی جدا** از BotFather بساز و ربات اصلی را برای سرور نگه دار.

## ۰. پیش‌نیازها (برای همه مسیرها)

1. **ربات تلگرام:** در [@BotFather](https://t.me/BotFather) → `/newbot` → توکن را بردار. (دو بار: یکی برای تست، یکی اصلی.)
2. **شناسه عددی تلگرامت:** به [@userinfobot](https://t.me/userinfobot) پیام بده (یا بعداً به ربات `/id` بفرست).
3. **کلید Anthropic API:** در [console.anthropic.com](https://console.anthropic.com) → Billing (شارژ اعتبار) → API Keys.
   در بخش **Limits** یک سقف خرج ماهانه بگذار (مثلاً ۳۰ دلار) تا هزینه از کنترل خارج نشود.
4. اختیاری: `OPENAI_API_KEY` برای ویس، توکن GitHub، و کلیدهای گوگل (README بخش ۳).
5. دو فایل شخصی که داری: `.env` (کلیدها را در آن پر کن) و `profile.md`.

## A. تست با GitHub Codespaces

1. کد روی GitHub است (شاخه پیش‌فرض ریپو).
2. **Secrets:** GitHub → Settings → Codespaces → **New secret**، و برای هر کدام به ریپوی LifeAgent دسترسی بده:
   `TELEGRAM_BOT_TOKEN` (توکن ربات **تستی**)، `TELEGRAM_ALLOWED_USER_IDS`، `ANTHROPIC_API_KEY`، و اختیاری `OPENAI_API_KEY`، `GITHUB_PERSONAL_ACCESS_TOKEN`.
   (تنظیمات غیرمحرمانه مثل ساعت روال‌ها از مقدارهای پیش‌فرض می‌آیند؛ برای یادآور اذان یک secret به نام `PRAYER_REMINDERS` با مقدار `true` هم بساز.)
3. در صفحه ریپو: **Code → Codespaces → Create codespace** روی شاخه درست (ماشین ۲ هسته‌ای کافی است). نصب خودکار چند دقیقه طول می‌کشد.
4. فایل `profile.md` را با کشیدن و رها کردن در پوشه `workspace/memory/` آپلود کن.
5. در ترمینال codespace:
   ```bash
   python -m lifeagent.doctor --live     # همه چیز ✅ شد؟ (یک درخواست خیلی کوچک به مدل می‌فرستد)
   python -m lifeagent                    # ربات روشن شد؛ برو سراغ تلگرام
   ```
6. **مهم برای سهمیه رایگان:** بعد از تست، codespace را **Stop** کن (Codespaces → … → Stop). در Settings → Codespaces می‌توانی Default idle timeout را تنظیم کنی.

## B. اجرای دائمی روی Oracle Cloud Always Free (پیشنهادی)

### ۱. ساخت سرور
1. در [oracle.com/cloud/free](https://www.oracle.com/cloud/free/) حساب بساز (کارت بین‌المللی برای احراز هویت لازم است؛ در طرح Always Free چیزی کم نمی‌شود). Home region را نزدیک انتخاب کن (مثلاً Frankfurt). بعد از ساخت، region عوض نمی‌شود.
2. **Compute → Instances → Create instance:**
   - Image: **Ubuntu 24.04**
   - Shape: **Ampere → VM.Standard.A1.Flex** با **2 OCPU و 12 GB RAM** (داخل سهمیه رایگان)
   - SSH keys: کلید عمومی‌ات را آپلود کن یا بگذار بسازد و کلید خصوصی را دانلود کن.
   - اگر خطای **Out of capacity** گرفتی: Availability Domain دیگر را امتحان کن یا چند ساعت بعد دوباره.
3. **جلوگیری از پس‌گرفتن سرور:** Oracle ممکن است VMهای Always Free را که در ۷ روز خیلی کم‌مصرف بوده‌اند (CPU، شبکه و رم زیر ۲۰٪) پس بگیرد. ربات ما بیشتر وقت بیکار است. راه مطمئن: حساب را به **Pay As You Go** ارتقا بدهی. تا وقتی داخل سهمیه Always Free بمانی، هزینه‌ای ندارد.
4. ورود:
   ```bash
   ssh -i ~/path/to/key ubuntu@<PUBLIC_IP>
   ```
   ربات ما پورت ورودی لازم ندارد، چون خودش به تلگرام وصل می‌شود.

### ۲. نصب ربات
روی سرور:
```bash
# اگر ریپو خصوصی است، یک fine-grained token با دسترسی Read به این ریپو بساز:
git clone https://<TOKEN>@github.com/Kyzen-dev/LifeAgent.git ~/lifeagent
```
از کامپیوتر خودت دو فایل شخصی را بفرست:
```bash
scp -i ~/path/to/key .env ubuntu@<PUBLIC_IP>:~/lifeagent/.env
scp -i ~/path/to/key profile.md ubuntu@<PUBLIC_IP>:~/lifeagent/workspace/memory/profile.md
```
بعد روی سرور:
```bash
cd ~/lifeagent
bash deploy/setup-server.sh
```
این اسکریپت به ترتیب:
1. اگر رم کم باشد swap می‌سازد.
2. Docker را نصب می‌کند.
3. image را می‌سازد (بار اول ۵ تا ۱۰ دقیقه).
4. ربات را با `restart: unless-stopped` روشن می‌کند، که بعد از ری‌استارت سرور هم خودش بالا می‌آید.
5. در آخر `doctor` را اجرا می‌کند.

### ۳. کارهای روزمره
```bash
cd ~/lifeagent
docker compose logs -f --tail 100                                 # لاگ زنده
docker compose restart                                            # ری‌استارت
git pull && docker compose up -d --build                          # به‌روزرسانی کد
docker compose run --rm lifeagent python -m lifeagent.doctor --live   # چک سلامت کامل
tar czf ~/backup-$(date +%F).tgz data workspace/memory workspace/notes   # پشتیبان
```
پشتیبان را هر از گاهی با `scp` روی کامپیوتر خودت هم بیاور.

## C. Google Cloud e2-micro (جایگزین)
1. در Google Cloud یک VM از نوع **e2-micro** در یکی از regionهای رایگان (`us-west1`، `us-central1` یا `us-east1`) بساز، با دیسک **30 GB standard** و Ubuntu 24.04.
2. از SSH داخل کنسول وارد شو و همان مراحل «نصب ربات» مسیر B را برو. اسکریپت خودش ۲ گیگ swap اضافه می‌کند. build کندتر است، ولی ربات اجرا می‌شود.

## چک‌لیست تست (بعد از راه‌اندازی)

هر مورد را در تلگرام بفرست و نتیجه را تیک بزن. اگر چیزی درست کار نکرد، خروجی `docker compose logs --tail 200` را نگه دار.

**پایه**
- [ ] `/start` → راهنما می‌آید. از یک حساب دیگر تلگرام → ربات جواب **نمی‌دهد** (امنیت).
- [ ] «سلام، بیا با هم آشنا بشیم» → onboarding شروع می‌شود و بخش «راه‌اندازی اولیه» پروفایل اجرا می‌شود (ساخت عادت‌ها، اهداف و وزن اولیه).
- [ ] «عادت‌هام رو نشون بده» → عادت‌های ساخته‌شده دیده می‌شوند.
- [ ] `/new` و بعد «من کی هستم؟» → از حافظه بلندمدت (پروفایل) جواب می‌دهد.

**فریلنس و Upwork**
- [ ] «یه مشتری جدید: X، پروژه چت‌بات RAG، ساعتی ۱ میلیون» → مشتری و پروژه ثبت می‌شوند.
- [ ] «شروع کار روی چت‌بات» → چند دقیقه بعد «تموم کردم، retriever رو درست کردم» → زمان ثبت می‌شود.
- [ ] «این هفته چند ساعت کار کردم؟» → گزارش ساعت و درآمد تقریبی.
- [ ] متن یک آگهی Upwork را بفرست → امتیاز تناسب + دو نسخه پروپوزال. بعد «فرستادمش، ۱۲ کانکت» → ثبت به‌عنوان proposal.
- [ ] «آمار پروپوزال‌های آپورک؟» → قیف تبدیل.
- [ ] «پروفایل آپورکم رو از صفر بنویس» → Title، Overview و ایده‌های portfolio.

**مالی، سلامت و عادت‌ها**
- [ ] «۲۵۰ تومن ناهار» → هزینه ثبت می‌شود. «این ماه چقدر خرج کردم؟» → خلاصه.
- [ ] عکس یک رسید → استخراج و ثبت.
- [ ] «وزنم ۶۰.۵ شد» → ثبت؛ «برنامه افزایش وزنم چیه؟» → برنامه با هدف کالری و پروتئین.
- [ ] «امروز ۲۰ دقیقه مدیتیشن کردم» → ثبت عادت.

**یادآور و روال‌ها**
- [ ] «۵ دقیقه دیگه یادم بنداز آب بخورم» → سر وقت پیام با دکمه‌های «انجام شد» و «تعویق».
- [ ] یادآور اذان در زمان شرعی می‌آید (اگر `PRAYER_REMINDERS=true`) و دکمه «خواندم» ثبت می‌کند.
- [ ] `/brief` → گزارش صبحگاهی همین الان. `/review` → بازبینی هفتگی.
- [ ] برای تست روال‌ها بدون صبر: در `.env` مقدار `MIDDAY_CHECKIN_TIME` را چند دقیقه بعد بگذار، `docker compose up -d` کن و منتظر بمان. اگر چیزی برای گفتن نباشد پیامی نمی‌آید، و این درست است.

**ورودی‌ها و خروجی‌ها**
- [ ] ویس فارسی و ویس انگلیسی → متن درست و جواب (اگر کلید OpenAI داری).
- [ ] یک PDF بفرست → خلاصه. «خلاصه‌اش رو PDF کن» → دکمه تأیید اجرا → فایل PDF با فارسی درست.
- [ ] «هزینه‌های این ماه رو اکسل کن» → فایل xlsx.

**امنیت و تأیید**
- [ ] «یه ایمیل به test@example.com بفرست» (اگر گوگل وصل است) → حتماً دکمه تأیید می‌آید و با «رد» ارسال نمی‌شود.
- [ ] یک کار Bash → دکمه «تأیید موارد مشابه تا ۳۰ دقیقه» دیده می‌شود.
- [ ] `/cost` → هزینه امروز.

**رشد AI**
- [ ] «تو LangGraph چطور human-in-the-loop بذارم؟» → جواب با مستندات به‌روز (Context7).
- [ ] «خلاصه اخبار AI این هفته» → خبرها با لینک + ایده پست.
- [ ] «یه پست لینکدین درباره تجربه‌ام با RAG بنویس» → دو نسخه انگلیسی.

## رفع اشکال

| مشکل | علت و راه‌حل |
|---|---|
| ربات اصلاً جواب نمی‌دهد | `docker compose logs`؛ شناسه‌ات در `TELEGRAM_ALLOWED_USER_IDS` درست است؟ |
| `Conflict: terminated by other getUpdates request` | همین توکن جای دیگری هم اجرا است (Codespaces و سرور با هم). یکی را خاموش کن یا ربات تستی جدا بساز |
| `permission denied` روی `data/` | `sudo chown -R 1000:1000 data workspace` |
| build روی سرور ۱ گیگی kill شد | swap را چک کن (`free -h`)؛ اسکریپت را دوباره اجرا کن |
| `doctor` می‌گوید Anthropic خطا | کلید یا اعتبار (Billing) را چک کن؛ `--live` پیام دقیق را نشان می‌دهد |
| یادآور اذان نمی‌آید | `doctor` بخش prayer times؛ اگر aladhan.com در دسترس نباشد، ربات هر ۳۰ دقیقه دوباره امتحان می‌کند |
| هزینه زیاد است | `/cost`؛ `LIFEAGENT_EFFORT=low`؛ روال‌های غیرضروری را خالی بگذار؛ سقف خرج در کنسول Anthropic |
